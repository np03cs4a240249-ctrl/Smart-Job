#  Smart Job Application

Smart Job Application is a modern web platform that helps users find jobs efficiently using smart filtering, tracking, and AI-based recommendations.

---

##  Features

-  User Authentication (Login & Registration)
-  User Profile Management
-  Job Search with Filters (location, category, salary)
-  Job Application System
-  Basic AI Job Matching
-  Application Tracking Dashboard
-  Fully Responsive Design
